# Лабораторная работа 1

## Задание
Реализовать серверное приложение на Go с шаблонами, списком услуг, карточкой услуги и просмотром заявки на оксигенацию. Для медиафайлов подключить локальное хранилище MinIO.

## Что сделано
- Выведен список услуг на странице `/services`.
- Добавлен поиск услуг через параметр `query`.
- Сделана карточка услуги по адресу `/services/{id}`.
- Сделан просмотр заявки по адресу `/oxygenation_request/{id}`.
- Подключены шаблоны, общая шапка и стили.
- Подготовлены изображения и видео услуг для MinIO.

## Запуск
1. Проверить проект: `go test ./...`
2. Запустить сервер: `go run ./cmd/rip`
3. Открыть страницу: `http://localhost:8080/services`

Если порт `8080` занят:
```powershell
$env:APP_PORT="8081"
go run ./cmd/rip
```

## MinIO
1. Запустить контейнер: `docker compose up -d minio`
2. Открыть консоль: `http://localhost:9001`
3. Войти под пользователем `root` с паролем `rootroot`.
4. Создать хранилище `images`.
5. Загрузить файлы `normal`, `mild`, `moderate`, `severe` с расширениями `.png` и `.mp4`.
6. Разрешить чтение файлов из хранилища.

## Основные файлы
- `cmd/rip/main.go` — точка входа.
- `internal/api/server.go` — сервер и маршруты.
- `internal/app/handler/handler.go` — обработчики страниц.
- `internal/app/repository/repository.go` — данные услуг и заявок.
- `templates` — шаблоны страниц.
- `resources/styles/style.css` — стили.
