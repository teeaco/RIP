# Серверная часть сервиса заявок на оксигенацию

## Задание
Оформить репозиторий GitHub с исходным кодом серверной части проекта.

## Ссылка на фронтенд
- https://github.com/teeaco/oxygenation_index_spa

## Что находится в репозитории
- `main` — общая страница проекта.
- `basic-disign` — лабораторная работа 1: сервер на Go, шаблоны, список услуг и просмотр заявки.
- `db_int` — лабораторная работа 2: база данных PostgreSQL, модели GORM и связь заявок с услугами.
- `oxygenation-rest-api` — лабораторная работа 3: программный интерфейс для услуг, заявок и пользователей.
- `lab4-auth-swagger-session-redis` — лабораторная работа 4: регистрация, вход, выход, роли, сессии Redis и Swagger.

## Предметная область
Проект хранит услуги для оценки оксигенации, заявки пользователей и результаты расчёта индекса `PaO2 / FiO2`.
