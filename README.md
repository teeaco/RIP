# Лабораторная работа 4

## Задание
Добавить регистрацию, вход, выход, проверку ролей, сессии в Redis и Swagger-документацию для REST-интерфейса сервиса заявок на оксигенацию.

- Пользователь регистрируется через `/api/users/register`.
- Вход выполняется через `/api/users/login`.
- Выход выполняется через `/api/users/logout`.
- После входа сервер выдаёт токен доступа.
- Сессия пользователя хранится в Redis.
- Методы заявок и изменения услуг требуют авторизацию.
- Модератор может завершать или отклонять сформированные заявки.
- Создатель видит свои заявки, модератор видит все заявки.
- Swagger доступен по адресу `/api/swagger`.

## Запуск
1. Поднять инфраструктуру:
```powershell
docker compose up -d db adminer minio redis
```

2. Запустить сервер:
```powershell
$env:DB_HOST='127.0.0.1'
$env:DB_PORT='55632'
$env:DB_USER='root'
$env:DB_PASSWORD='root'
$env:DB_NAME='RIP'
$env:DB_SSLMODE='disable'
$env:REDIS_ADDR='127.0.0.1:6379'
$env:REDIS_PASSWORD='password'
$env:JWT_SECRET='lab4-dev-secret'
go run ./cmd/rip
```

Активный адрес сервер пишет в журнал запуска. По умолчанию используется порт `8095`, запасной порт — `8096`.

## Проверка
1. Зарегистрировать пользователя.
2. Выполнить вход и сохранить токен доступа.
3. Передать токен в заголовке `Authorization`.
4. Создать черновик заявки и добавить услуги.
5. Сформировать заявку.
6. Войти модератором и завершить или отклонить заявку.
7. Выполнить выход и проверить, что сессия удалена из Redis.
8. Открыть `/api/swagger` и сверить методы.

## Основные файлы
- `internal/api/server.go` — запуск сервера и подключение сервисов.
- `internal/app/rest/handler.go` — методы REST-интерфейса.
- `internal/app/rest/swagger.go` — Swagger-документация.
- `internal/app/security` — токены и сессии.
- `internal/app/repository/repository.go` — модели и работа с базой.
